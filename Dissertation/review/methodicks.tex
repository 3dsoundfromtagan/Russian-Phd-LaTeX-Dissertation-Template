\subsection{Основные методики обработки температурных кинетик}
Для расчёта коэффициента оптического поглощения из экспериментальных данных о кинетике температуры с использованием уравнения теплового баланса \ref{eq:balance_equation} применяют следующие основные методики:


\subsubsection{Экспоненциальный метод}
Поскольку решением балансного уравнения являются экспоненциальные зависимости, представляется возможным аппроксимировать экспериментальные данные для перегрева кристалла относительно комнатной температуры $\Delta T := T(t) - T_a$ следующей формулой:
\begin{equation}
	f(t) = A + Be^{-Ct}
	\label{eq:exp_fit}
\end{equation}

при нагреве ($t < t_0$) и остывании ($t > t_0$) соответственно. Сравнивая аппроксимирующую функцию (\ref{eq:exp_fit}) с решением уравнения теплового баланса (\ref{eq:balance_equation_solution}), получаем выражение для усреднённого теплового источника:

\begin{equation}
	E = A_{\text{exp}}C_{\text{exp}} = \overline{Q},
	\label{eq:barq_exp}
\end{equation}


Отметим, что при аппроксимации кинетики остывания данный метод будет совпадать с импульсным, поэтому далее под экспоненциальным методом мы будем понимать аппроксимацию участка кинетики, отвечающего за нагрев образца лазерным излучением. Величины, полученные аппроксимацией кинетики нагрева, далее обозначены индексом <<exp>>, а кинетики остывания --- индексом <<puls>>.



Применение методики ограничено в случае низкого коэффициента теплопроводности образца, вернее, в случае малого числа Био, характеризующего однородность распределения температуры по образцу \( b = \frac{hR}{\varkappa} \). Здесь \( R \) — характерные линейные размеры образца, \( \varkappa \) — коэффициент теплопроводности.   Это обусловлено тем, что кинетики нагрева будут отличаться при разных положениях термодатчика относительно лазерного пучка, о чем будет сказано в описании импульсного метода.






\subsubsection{Импульсный метод}
В импульсном методе требуется произвести экстраполяцию кинетики охлаждения до середины времени включения лазера $t=t_0/2$ и использовать экстраполированную температуру для расчёта поглощения.

Согласно (\ref{eq:balance_equation_solution}), значение экстраполированной по кинетике остывания температуры в этот момент времени составляет

\begin{equation}
	T(t_0/2) = T_a + \dfrac{\overline{Q}}{\Gamma}\left(1-\exp{(-\Gamma t_0)}\right)\exp{(\Gamma t_0/2)} = T_a + 2\dfrac{\overline{Q}}{\Gamma}\sinh{\left(\Gamma t_0 / 2\right)},
	\label{eq:T05}
\end{equation}

Отсюда получаем выражение для среднего теплового источника, определяемого по результатам экстраполяции кинетики остывания:

\begin{equation}
	I = \frac{C_{\text{puls}}f(t_0/2)}{2\sinh(C_{\text{puls}}t_0/2)} = \overline{Q}.
	\label{eq:barq_puls}
\end{equation}

В области охлаждения все отличия по теплопроводности, связанные с зависимостью кинетики от положения термодатчика, сходятся к одной кривой, поскольку при остывании градиент температуры внутри материала успевает выравняться значительно быстрее, чем происходит теплообмен с окружающей средой). Это означает, что кинетика остывания на поздних стадиях становится универсальной и не зависит от начального распределения температуры, созданного в момент нагрева. Данное свойство делает импульсный метод перспективным для определения коэффициента оптического поглощения при низких значениях числа Био.

\subsubsection{Градиентный метод}


В градиентном методе анализируется разность производных температуры в моменты времени, соответствующих одной и той же температуре \( T_0 \) при нагреве и охлаждении:


\begin{equation}
	G = \frac{d T}{d t} \bigg|_{t < t_0, T = T_0} - \frac{d T}{ t} \bigg|_{t > t_0, T = T_0}.
	\label{eq:barq_grad}
\end{equation}


Из (\ref{eq:barq_grad}) следует, что при неизменной температуре окружающей среды \( G \equiv \overline{Q} \).

На рис. 1.4 проиллюстрировано использование всех трёх методик для обработки температурной кинетики.

Конечная теплопроводность образца (малое число Био) вносит погрешности во все рассмотренные методики измерений, однако наибольшее влияние она оказывает на градиентный метод \cite{Meja1997}. Это связано с выраженной зависимостью величины $G$ от расположения внешнего термодатчика. Именно данное ограничение послужило причиной исключения градиентного метода из стандарта ISO 11551 в 2003 году \cite{iso_old}. Тем не менее, только этот метод обеспечивает возможность регистрации временной динамики коэффициента оптического поглощения, что, например делает его подходящим инструментом для изучения процессов деградации оптических элементов под воздействием лазерного излучения \cite{Zotov2023}.

Помимо упомянутых выше, в различных работах \cite{willamowski1999standardisierbare} представлены такие методы, как, например, интегральный и метод отклика (Responseverfahren).
